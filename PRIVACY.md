# Privacy Policy — T.R.A.U.T.H. Home

This is a private, personal Home Assistant setup used only by the household that runs it.

- Google Calendar access is used solely to show the household's own upcoming events on its home dashboard.
- Calendar data stays on the household's Home Assistant device and is not sold, shared, or sent to any third party.
- Access can be removed at any time at https://myaccount.google.com/permissions.

Contact: the repository owner on GitHub.
